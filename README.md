# Salah Parcel Tracker 

## Files

- `main.py`
  - Homepage / main menu
  - Shared parcel data
  - Connects Customer and Courier modules

- `customer.py`
  - Customer menu
  - Track parcel
  - Tracking status
  - Receiver information
  - Parcel details

- `courier.py`
  - Courier menu
  - Dashboard
  - Parcel list
  - Update parcel status

## Run

From the project folder:

```bash
python3 main.py
```
